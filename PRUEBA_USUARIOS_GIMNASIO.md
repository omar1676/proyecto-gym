## Cómo realizar la sesión

1. La persona empleada maneja la aplicación; el observador no le indica dónde pulsar salvo que quede bloqueada.
2. Se cronometra desde que se formula la tarea hasta que la persona confirma que ha terminado.
3. No se cambian permisos para facilitar una tarea y no se usa ningún dato biométrico.
4. Se usan datos de prueba identificables o una operación real previamente autorizada y controlada.
5. Cada problema se copia después a `FEEDBACK_PILOTO.md` con prioridad P0, P1, P2, P3 o IDEA.

Los clics de referencia cuentan botones, enlaces y confirmaciones. No cuentan la escritura ni la selección de una opción. Sirven para detectar desvíos, no para dirigir a la persona.
